# Mathematics

This is the mathematics-chair workspace for our middle-school Science Bowl team. Keep original source PDFs in `past exams/`; use this folder for math-specific teaching and practice materials.

## Folders

- `lecture notes/` - lesson notes, topic summaries, and worked examples.
- `textbooks/` - permitted textbook excerpts, references, and source notes.
- `worksheets/` - student-facing practice worksheets.
- `worksheet answers/` - answer keys matching the worksheet filenames.
- `homework/` - assigned problems, due-date instructions, and submitted-model solutions where appropriate.

Use lowercase descriptive filenames, such as `number_theory_modular_arithmetic.md` or `algebra_linear_equations_worksheet.pdf`. Pair a worksheet with an answer key using the same base name.
