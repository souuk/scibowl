# Middle School Science Bowl

This repository contains middle-school Science Bowl preparation materials, including lecture notes, homework, answer keys, textbooks, and an archive of U.S. Department of Energy practice questions. Topic maps and a question-packet inventory support subject preparation and resource discovery.

## Repository architecture

```text
scibowl/
├── README.md                     # Repository description and architecture
├── subjects/
│   ├── subjects.md               # Subject labels and archive coverage
│   └── mathematics/
│       ├── topics.md             # Topic map
│       ├── lecture notes/        # Lecture PDFs and reference notes
│       ├── homework/             # Homework assignments
│       ├── homework answers/     # Homework solutions
│       └── textbooks/            # Reference textbooks
├── past exams/
│   ├── *.pdf                     # DOE middle-school question packets
│   └── MANIFEST.csv              # Packet filenames and source URLs
└── analytics/
    └── pdf_inventory.md          # Packet pages, question markers, and labels
```
