# DOE National Science Bowl Middle School Past Exams

This folder is a local, study-ready copy of every question PDF linked from the DOE National Science Bowl Middle School Sample Questions page. It is intended for practice, question lookup, and curriculum/topic review. The source page warns that some historical answers may be outdated, so use the original DOE material as the authority.

## Naming convention

- `msnsb_set##_round##.pdf` - a numbered PDF from a DOE sample set.
- `msnsb_<descriptive_source_name>.pdf` - a supplemental DOE PDF outside that pattern.
- All filenames are lowercase for consistent sorting and cross-platform use.

## What's here

- 251 verified PDFs
- 3,201 pages
- 11,704 toss-up/bonus markers found in extracted text

`MANIFEST.csv` maps every local filename to its DOE URL and byte size. The `analytics/` folder contains Markdown reports generated from the PDF text.
